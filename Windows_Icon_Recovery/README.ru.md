# Windows Icon Recovery

[English](README.md) | [Русский](README.ru.md)

[К DSN Tools](../README.ru.md)

Сохраняет, проверяет и восстанавливает `IconResource` папок и `IconLocation` ярлыков `.lnk` по версионированному JSON-манифесту.

Восстановление меняет только отсутствующие или пустые назначения. Другая непустая иконка считается конфликтом. Перед записью каждый изменяемый файл копируется в резервную папку с контрольной суммой SHA-256, после чего результат повторно проверяется.

## Стек

Windows PowerShell 5.1, COM-автоматизация Windows Shell и уведомления Explorer.

## Требования

- Windows 10 или 11
- Права на изменение целевого `desktop.ini`, ярлыка и файловых атрибутов
- Абсолютные пути к целям и источникам иконок после раскрытия переменных окружения
- Доступная для записи папка резервных копий при восстановлении

## Обмен данными

Схема манифеста:

```json
{
  "version": 1,
  "folders": [
    { "path": "%USERPROFILE%\\Example", "icon": "%SystemRoot%\\system32\\shell32.dll,3" }
  ],
  "shortcuts": [
    { "path": "%USERPROFILE%\\Desktop\\Example.lnk", "icon": "%SystemRoot%\\system32\\shell32.dll,3" }
  ]
}
```

Цели должны быть уникальными. Переменные окружения сохраняются в манифесте без раскрытия. Пример: [`examples/icon-manifest.example.json`](examples/icon-manifest.example.json).

Команды возвращают структурированный JSON. Результаты проверки и восстановления содержат сведения о проблемах или конфликтах.

## Эксплуатация

### Использование

#### Сохранение

```powershell
.\Export-IconManifest.ps1 `
  -OutputPath .\icons.json `
  -Folder '%USERPROFILE%\Example' `
  -Shortcut '%USERPROFILE%\Desktop\Example.lnk'
```

#### Аудит

```powershell
.\Test-IconAssignments.ps1 -ManifestPath .\icons.json
```

Код `0` означает отсутствие проблем; `1` — найденную проблему или ошибку входных данных.

#### Восстановление

```powershell
.\Restore-IconAssignments.ps1 `
  -ManifestPath .\icons.json `
  -BackupRoot "$env:USERPROFILE\Icon Recovery Backups"
```

Код `0` означает, что восстановленное состояние прошло проверку. Код `2` означает отсутствующую цель или конфликт назначения; код `1` — ошибку или неудачную итоговую проверку.

Возвращаемая папка резервной копии содержит манифест и копии измененных файлов. Для отката проверь контрольную сумму и верни каждую копию в указанный `sourceFile`; файлы со значением `existed: false` удали. Атрибуты папки могут потребовать отдельного отката, поскольку восстановление добавляет необходимый Explorer флаг `ReadOnly`.

### Проверка

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\Test-IconRecovery.ps1
```

## Ограничения

- Отсутствующие файлы с иконками выявляются, но не восстанавливаются
- Конфликтующие непустые назначения не перезаписываются
- Explorer может некоторое время показывать закешированную иконку после уведомления об изменении
